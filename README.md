# 条码生成器

适用于 iOS [Scripting](https://scripting.fun/) 应用的原生条码生成脚本，支持批量生成、扫描填充、收藏、历史记录、备份和桌面小组件。

## 添加到 Scripting

请在已安装 Scripting 的 iPhone 或 iPad 上点击：

[一键添加到 Scripting](https://scripting.fun/import_scripts?urls=%5B%22https%3A%2F%2Fgithub.com%2Fluckyalanzhou%2FBarcode-generator-for-Scripting%22%5D)

在 Scripting 显示导入页面后确认导入，`条码生成器` 就会添加到应用首页。再次导入前请先确认是否需要保留现有脚本中的本地数据。

也可以在 Scripting 首页使用导入功能，手动粘贴以下仓库地址：

```text
https://github.com/luckyalanzhou/Barcode-generator-for-Scripting
```

## 使用

- 直接打开脚本：生成、收藏和管理条码。
- 长按底部标签：快速扫描填充、导入导出备份或清空历史。
- 添加 Scripting 桌面小组件并选择本脚本：在 iOS 主屏幕显示收藏条码。
